# Лабораторная работа №1. Работа с сокетами

## Цель работы 
Понять принципы межсокетного взаимодейсвтия в вебе. Научиться реализовывать базовую архитектуру клиент-сервер

## Задания

| № | Тема | Файлы |
|---|------|-------|
| 1 | Обмен сообщениями | `UDPServer.java`, `UDPClient.java` |
| 2 | Вычисления (квадратное уравнение) | `TCPServer.java`, `TCPClient.java` |
| 3 | Раздача HTML-страницы | `HTTPServer.java`, `index.html` |
| 4 | Многопользовательский чат | `ChatServer.java`, `ChatClient.java` |
| 5 | Веб-сервер GET/POST | `WebServer.java` |
